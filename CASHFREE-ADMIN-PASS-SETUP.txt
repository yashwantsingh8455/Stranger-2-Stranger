RENDER ENVIRONMENT VARIABLES
----------------------------
Reuse the SAME Cashfree Payment Gateway credentials already used by your other payment flow:

CASHFREE_CLIENT_ID=...
CASHFREE_CLIENT_SECRET=...

Aliases also supported:
CASHFREE_APP_ID=...
CASHFREE_SECRET_KEY=...

Required:
CASHFREE_ENV=production
CASHFREE_API_VERSION=2026-01-01
PUBLIC_BASE_URL=https://strangertostranger.onrender.com

For Cashfree testing, temporarily use:
CASHFREE_ENV=sandbox

CASHFREE DASHBOARD

SECURITY
--------
- Never put Cashfree client secret in HTML/JS/GitHub.
- The backend verifies order status before giving 30-day access.
- Webhook signatures are verified before processing.
- Paid admins cannot access /admin, email registry, IP/session data, UID bans, full-site clear, or master controls.
